# 📊 Superstore Sales Analysis – Excel Dashboard

## 📌 Project Overview

This project is an **Excel-based Superstore Sales Analysis Dashboard** created to analyze sales, profit, customers, products, categories, segments, regions, and shipping modes.

The objective is to convert raw sales data into meaningful business insights using **Microsoft Excel, data preparation, PivotTables, charts, slicers, and dashboard reporting**.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Compare sales across regions and categories.
- Identify high-performing customer segments.
- Understand category-wise profitability.
- Analyze sales by state and business segment.
- Build an interactive executive dashboard.
- Present business insights in a clear and professional format.

---

## 🗂️ Workbook Structure

The Excel workbook contains the following sheets:

| Sheet Name | Description |
|---|---|

## 💡 Business Insights

- The West region contributes the highest sales among the listed regions.
- Technology is the highest-sales category in the analytical summary.
- Technology also contributes the highest category-wise profit.
- The Consumer segment contributes the largest share of sales.
- Furniture has comparatively lower profit than Technology and Office Supplies, making it a useful area for further analysis.
- Dashboard filters can be used to investigate sales performance by region, category, segment, and shipping mode.

## ▶️ How to Use This Project

1. Download or clone this repository.

4. Use slicers and timeline filters to explore the data.
5. Review the `Analytical_Summary` sheet for summarized metrics.
6. Read the `Business_Insights` and `Project_Documentation` sheets for additional information.
